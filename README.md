# Project Office Hub

Repositorio para la futura unificación de Project Office Hub / PMO y ResumenEjecutivoSemana.

Project Office Hub será la aplicación principal y el seguimiento ejecutivo semanal se integrará como un módulo interno de cada proyecto.

## Estado actual

Repositorio inicializado el 1 de octubre de 2026. El 2 de octubre se realizó el análisis estático inicial de ambos proyectos y se documentó el plan de integración. La implementación y la ejecución del baseline de pruebas están pendientes.

Los proyectos originales se conservan intactos. Este repositorio todavía no contiene código de la aplicación.

Rama principal: `master`.
